# How to Install the Elysium Module in FoundryVTT

## Step 1: Get the Manifest URL

Copy this URL (it's the link to install the module):

```
https://raw.githubusercontent.com/blargen/elysium/main/module.json
```

## Step 2: Open FoundryVTT

1. Launch FoundryVTT
2. Go to the **Game Worlds** tab
3. Click on your D&D 5e world (or create one if you don't have one)

## Step 3: Install the Module

1. Click **"Add-on Modules"** at the top
2. Click the **"Install Module"** button at the bottom
3. Paste the manifest URL into the box at the bottom that says **"Manifest URL"**
4. Click **"Install"**

## Step 4: Enable the Module

1. After installation, you'll see "Elysium" in your module list
2. Check the box next to **Elysium** to enable it
3. Click **"Save Module Settings"**

## Step 5: Launch Your World

1. Go back to the Game Worlds tab
2. Click **"Launch World"**
3. You're done! The module is now active

---

**Troubleshooting:**

- If it says "Module not found", double-check the manifest URL
- Make sure you have the D&D 5e system installed first
- Current version should be **0.1.3**

That's it! The module will load automatically whenever you start the world.
