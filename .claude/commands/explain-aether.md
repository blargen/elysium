Explain the Elysium aether fuel system in simple terms:

1. **What is aether?** Fuel for mods (like spell components)

2. **The 5 quality tiers:**

   - Rarefied (enhanced bonuses)
   - Prometheum (premium bonuses)
   - Wild (chaotic, unpredictable)

3. **The flow:**
   - Use a mod → Select aether → Consume fuel → Apply effects → Mod activates

4. **Module hooks architecture:**
   - Items = just flags (no macros!)
   - Module detects via hooks
   - Centralized logic

5. **Unrefined toxicity system:**
   - Daily doses tracking
   - ATL (Aether Toxicity Level)
   - Progressive conditions
   - Resets on long rest
